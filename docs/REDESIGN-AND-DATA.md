# 2027 资料核对与日式 UI 改版

## 范围与进度

以学校官网与 JASSO 为来源。`school-review-2027.json` 为逐校清单；`data/school-reviews.ts` 只标注已经核对的字段，不表示该校全部资料核验完毕。当前首批覆盖东京大学、京都大学、东北大学和 ISI 东京校区的部分字段，其余逐批继续。旧招生年份、排名、分数门槛、教授信息与其他专业不能视为2027最新资料。

页面展示的院校信息目前来自本地 TypeScript 数据文件。Supabase 是另一份数据副本，不会自动驱动这些院校页面；更新时必须同步维护两者。

## 首批变更

- 东京大学：区分本科与修士学费，校正研究生月学费，从可选课程移除已关闭的 PEAK，保留停招说明。
- 京都大学：核对现行学费；iUP 2027 计划40名、9个学部参与，修正“全英文”的误导描述，补充2027申请期。
- 东北大学：2027年4月起新入学、持留学在留资格的本科与修士年学费90万日元，注明博士与专业职课程不在本次调整范围；同步费用详情与四年学费口径。
- ISI：东京校区2027–2028首年总费用101.5万至111.5万日元，分开列示选考料、入学金、学费、教材及设施费，更新升学/职业日语课程。
- 首页：JASSO本科首年学费与入学金参考，生活费明确为2023调查全国均值，本站计算的合计不是2027报价。

官方来源链接随页面和核对清单保存。

## 验证与同步

`node scripts/audit-school-data.cjs --write` 验证核心数据并刷新完整清单。

`npm run build -- --webpack` 构建并执行 TypeScript 检查。本机默认 Turbopack 出现进程连接异常，Webpack 构建通过。

Supabase 当前配置域名无法解析，未进行远端写入。需要恢复原项目或配置有效项目连接后再同步。不要通过公开 `/api/seed` 批量重导：它使用逐条插入，并非本批安全增量更新。
