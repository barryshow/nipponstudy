# 2027 资料核对与日式 UI 改版

## 范围与进度

以学校官网与 JASSO 为来源。`school-review-2027.json` 为逐校清单；`data/school-reviews.ts` 只标注已经核对的字段，不表示该校全部资料核验完毕。前十二批已覆盖主要国公私立大学及42所语言学校的部分字段；第十三批继续核对横滨、关西、中部、九州的20条旧候选数据，其中11所可明确对应官网实体，9条因没有可靠的官方实体或项目对应关系而从展示数据中移除。第十四批核对最后10条遗留语言学校候选：7所可对应官网或法务省告示名录实体，3所（仙台YMCA、松山东云、高松日本语学院）在官方名录中不存在对应日语学校，已从展示数据移除。第十五批回到大学主线，重新核对广岛、神户、一桥、名古屋工业4所国立大学以及东京理科、芝浦工业、东京电机、青山学院、中央、近畿、日本、东洋8所私立大学的费用、项目与2027入试口径，并补核上智、明治、立教、法政、同志社、东京大学、HAL东京与ISI的遗留表述；本批只改写已验证字段，不再新增无校方来源的排名、就业率与统一门槛。旧招生年份、排名、分数门槛、教授信息与其他专业不能视为2027最新资料。

页面展示的院校信息目前来自本地 TypeScript 数据文件。Supabase 是另一份数据副本，不会自动驱动这些院校页面；更新时必须同步维护两者。

## 验证与同步

`node scripts/audit-school-data.cjs --write` 验证核心数据并刷新完整清单。

`npm run build -- --webpack` 构建并执行 TypeScript 检查。本机默认 Turbopack 出现进程连接异常，Webpack 构建通过。

已核对的批次会通过带记录数前置校验的事务 SQL 同步至 Supabase；每次写入前后均查询目标记录核验。不要通过公开 `/api/seed` 批量重导：它使用逐条插入，并非本批安全增量更新。

批次 5（明治/立教/法政/同志社）、批次 6（东京理科/芝浦工业/东京电机/近畿）、批次 7（青山学院/中央/日本/东洋）、批次 8（修曼/ARC/京进/新宿御苑学院）、批次 9（千驮谷/九段/优尼塔斯/美罗斯）、批次 10（吉田/东亚/新宿日本语学校）、批次 11（大阪YMCA/京都民际/神户コミュニカ）、批次12（福冈YMCA/熊本YMCA/广岛YMCA）与批次13（横滨设计学院、GenkiJACS京都校、ECC、名古屋国际日本语学校、NSA、静冈国际语言学院、福冈两校、熊本外语专门学校日本语科、长野21、西日本国际教育学院）的 SQL 工件均已通过已配置的 Supabase 事务应用；每批写入前后均按目标 slug 查询并回查生效。批次13审查了20条旧候选，其中9条因无法确认真实官方身份而从展示数据中移除，未同步。批次14的 7 条已核实记录已于 **2026-11-04** 通过 `scripts/apply-reviewed-sync-batch-14-rest.cjs` 经 Supabase REST（publishable key，逐条 INSERT 并在写入后回读）应用；写入前确认这 7 个 slug 均不存在（远端当时共 29 条），写入后远端为 36 条，与本地 36 条 slug 集合完全一致，且 7 条记录的 17 个字段逐项比对无差异。因本机无法解析/连接 `db.<project>.supabase.co`、`DATABASE_URL` 密码对 pooler 返回 28P01，本批未使用事务 SQL；`scripts/reviewed-updates/2027-batch-14.sql` 保留为等价的可审计工件，其前置校验会在目标 slug 已存在时中止。恢复数据库密码后，后续批次应回到事务 SQL 流程。早期本机直连与匿名 REST 写入受网络、连接和RLS限制，均未用于本次同步。

批次15（广岛、神户、一桥、名古屋工业、上智、明治、立教、法政、同志社、东京理科、芝浦工业、东京电机、青山学院、中央、近畿、日本、东洋、东京大学共18条大学记录，HAL专门学校与ISI语言学校各1条）于 **2026-11-05** 通过 `scripts/apply-reviewed-sync-2027-consolidated.cjs` 经 Supabase REST（secret key，存在性前置判断后逐条 PATCH/INSERT，写入后逐字段回读）应用。本批选择按 slug 幂等比对而非逐条重写：每条记录仅 PATCH 与远端实际不一致的字段，无差异的记录不写入；本批 20 条目标记录远端均已存在，未触发 INSERT。写入后以 `scripts/diff-local-remote.cjs` 全表复核，University 55、VocationalSchool 30、LanguageSchool 36 条在三张表的 slug 集合、缺失、孤儿与字段内容上均无差异。`scripts/reviewed-updates/2027-batch-15.sql` 由 `scripts/prepare-reviewed-sync-2027-consolidated.cjs` 生成，保留为等价的可审计工件（按 slug 的 upsert，前置校验在任一目标 slug 缺失时中止，不含 DELETE）。
