# 2027 资料核对与日式 UI 改版

## 范围与进度

以学校官网与 JASSO 为来源。`school-review-2027.json` 为逐校清单；`data/school-reviews.ts` 只标注已经核对的字段，不表示该校全部资料核验完毕。前十二批已覆盖主要国公私立大学及42所语言学校的部分字段；第十三批继续核对横滨、关西、中部、九州的20条旧候选数据，其中11所可明确对应官网实体，9条因没有可靠的官方实体或项目对应关系而从展示数据中移除。第十四批核对最后10条遗留语言学校候选：7所可对应官网或法务省告示名录实体，3所（仙台YMCA、松山东云、高松日本语学院）在官方名录中不存在对应日语学校，已从展示数据移除。第十五批回到大学主线，重新核对广岛、神户、一桥、名古屋工业4所国立大学以及东京理科、芝浦工业、东京电机、青山学院、中央、近畿、日本、东洋8所私立大学的费用、项目与2027入试口径，并补核上智、明治、立教、法政、同志社、东京大学、HAL东京与ISI的遗留表述；本批只改写已验证字段，不再新增无校方来源的排名、就业率与统一门槛。第十六批转向工科与计算机类院校：东京农工、东京海洋、京都工艺纤维、九州工业、长冈技术科学、丰桥技术科学6所工科国立与1所计算机专门公立（会津），核对私费外国人留学生2027入试日程、EJU/英语门槛、学部学科构成与费用，其中丰桥的“学际共创课程”与九州工业的2027年度要项尚未最终确定，已在页面明确标注。第十七批处理剩余19所大学：11所公立、2所国立医科与6所私立（含私立医科），逐校核对2027年度私费或外国人留学生选抜的有无、日程、EJU与英语门槛、学部学科构成与学费；对不设外国人专用选抜的医科院校明确写明其选抜路径，避免把日本国内选抜当作留学生可报。旧招生年份、排名、分数门槛、教授信息与其他专业不能视为2027最新资料。

页面展示的院校信息目前来自本地 TypeScript 数据文件。Supabase 是另一份数据副本，不会自动驱动这些院校页面；更新时必须同步维护两者。
