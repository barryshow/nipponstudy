# 2027 资料核对与日式 UI 改版

## 范围与进度

以学校官网与 JASSO 为来源。`school-review-2027.json` 为逐校清单；`data/school-reviews.ts` 只标注已经核对的字段，不表示该校全部资料核验完毕。当前五批覆盖东京大学、京都大学、东京科学大学、大阪大学、东北大学、名古屋大学、北海道大学、九州大学、筑波大学、ISI 东京校区、早稻田、庆应、上智、立命馆与明治、立教、法政、同志社的部分字段，其余逐批继续。旧招生年份、排名、分数门槛、教授信息与其他专业不能视为2027最新资料。

页面展示的院校信息目前来自本地 TypeScript 数据文件。Supabase 是另一份数据副本，不会自动驱动这些院校页面；更新时必须同步维护两者。

## 验证与同步

`node scripts/audit-school-data.cjs --write` 验证核心数据并刷新完整清单。

`npm run build -- --webpack` 构建并执行 TypeScript 检查。本机默认 Turbopack 出现进程连接异常，Webpack 构建通过。

已核对的批次会通过带记录数前置校验的事务 SQL 同步至 Supabase；每次写入前后均查询目标记录核验。不要通过公开 `/api/seed` 批量重导：它使用逐条插入，并非本批安全增量更新。

批次 5（明治/立教/法政/同志社）的 SQL 工件 `scripts/reviewed-updates/2027-batch-05.sql` 已生成并就地核验，但**截至 2026-11-02 尚未应用到 Supabase**：本机无法直连 db 主机（仅 IPv6 记录）、代理隧道 5432 上游挂起、共享池化端点拒绝现有密码、REST 匿名密钥写入被 RLS 拦截。远端回查确认批次 1–4 已生效；批次 5 待有可用凭据后在事务中应用该工件。
