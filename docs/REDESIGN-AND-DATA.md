# 2027 资料核对与日式 UI 改版

## 范围与进度

以学校官网与 JASSO 为来源。`school-review-2027.json` 为逐校清单；`data/school-reviews.ts` 只标注已经核对的字段，不表示该校全部资料核验完毕。当前十批覆盖东京大学、京都大学、东京科学大学、大阪大学、东北大学、名古屋大学、北海道大学、九州大学、筑波大学、ISI 东京校区、早稻田、庆应、上智、立命馆与明治、立教、法政、同志社、东京理科、芝浦工业、东京电机、近畿、青山学院、中央、日本、东洋，以及修曼、ARC、京进、新宿御苑、千驮谷、九段、优尼塔斯、美罗斯、吉田、东亚和新宿日本语学校的部分字段，其余逐批继续。旧招生年份、排名、分数门槛、教授信息与其他专业不能视为2027最新资料。

页面展示的院校信息目前来自本地 TypeScript 数据文件。Supabase 是另一份数据副本，不会自动驱动这些院校页面；更新时必须同步维护两者。

## 验证与同步

`node scripts/audit-school-data.cjs --write` 验证核心数据并刷新完整清单。

`npm run build -- --webpack` 构建并执行 TypeScript 检查。本机默认 Turbopack 出现进程连接异常，Webpack 构建通过。

已核对的批次会通过带记录数前置校验的事务 SQL 同步至 Supabase；每次写入前后均查询目标记录核验。不要通过公开 `/api/seed` 批量重导：它使用逐条插入，并非本批安全增量更新。

批次 5（明治/立教/法政/同志社）、批次 6（东京理科/芝浦工业/东京电机/近畿）、批次 7（青山学院/中央/日本/东洋）、批次 8（修曼/ARC/京进/新宿御苑学院）、批次 9（千驮谷/九段/优尼塔斯/美罗斯）与批次 10（吉田/东亚/新宿日本语学校）的 SQL 工件均已于 **2026-11-02** 通过已配置的 Supabase 事务应用；每批写入前后均按目标 slug 查询并回查生效。批次 8 发现远端语言学校表只存在前三条，故在同一受保护事务中更新三条既有记录、显式新增一条已核实的新宿御苑学院记录；批次 10 也确认目标三条在远端缺失，故仅在相同保护下显式新增这三条已核实记录，未批量导入其余未核实本地数据。早期本机直连与匿名 REST 写入受网络、连接和 RLS 限制，均未用于本次同步；批次 1–10 的远端结果现已完成回查。
